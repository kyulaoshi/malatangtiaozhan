# 🌶️ 麻辣烫价格大挑战！ (마라탕 가격 맞추기)

중학교 중국어 수업용 개인전 게임입니다. 학생은 목표 가격을 확인하고, 중국식 종이 주문서에 재료를 체크한 뒤,
자기가 고른 재료만 들어간 마라탕을 완성하고 최종 가격을 발표합니다.

## 1. GitHub Pages로 배포하기 (가장 쉬운 방법)
1. GitHub에서 새 저장소(repository)를 만듭니다. 예: `malatang`
2. `index.html` 파일 **하나만** 업로드합니다. (Add file → Upload files)
3. Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 선택하고 Save
4. 1~2분 뒤 `https://내아이디.github.io/malatang/` 주소로 접속하면 끝!

`index.html` 한 파일 안에 게임 전체(React 포함)가 들어 있어 외부 서버·유료 API가 전혀 필요 없습니다.
인터넷이 끊겨도 동작하며, 인터넷이 되면 예쁜 중국어 글꼴(Google Fonts)이 추가로 적용됩니다.

## 2. 수업 진행 방법
- 목표 가격은 선생님이 **말로** 알려 주세요. 게임 안에서 따로 설정할 필요가 없습니다.
- 학생이 「开始游戏」을 누르면 바로 주문서가 나오고 타이머가 시작됩니다.
- 주문서 맨 위에서 **辣度(맵기)**를 하나 고릅니다: 不辣 / 微辣 / 中辣 / 特辣 (무료). 고른 맵기에 따라 국물 색이 달라집니다.
  시간이 끝날 때까지 고르지 않으면 不辣로 처리됩니다.
- 주문서에는 **한자, 한어병음, 가격만** 나옵니다. 그림과 한국어 뜻은 없습니다.
  그림과 한국어 뜻은 조리 화면과 결과 화면에서 처음 보입니다.
- 결과 화면에 내 가격과 발표 문장이 나옵니다. 학생이 선생님이 말한 목표 가격을 입력하면(선택) 차이를 계산해 줍니다.
- 「下一轮」을 누르면 새 주문서가 나옵니다. 라운드 수에는 제한이 없습니다.
- 제한 시간을 바꾸려면 주소 뒤에 `?time=90`처럼 붙여서 공유하세요. 기본은 60초입니다.

## 3. 재료·가격 바꾸기
`index.html`을 열면 맨 위쪽에 `window.MALATANG_CONFIG = { ... }` 블록이 있습니다.
여기서 `spice`(맵기 단계), `price`(가격), `zh`(중국어), `ko`(한국어), `time`(제한 시간), `closeRange`(“非常接近” 기준 차이)를 고치면 바로 반영됩니다.
GitHub 웹 화면에서 index.html → 연필(Edit) 버튼으로 수정하면 됩니다.
새 재료를 추가하면 그림 대신 `emoji` 값(예: `"emoji": "🌽"`)이 표시됩니다.

## 4. 게임 흐름
开始游戏 → 麻辣烫点菜单 작성(타이머, 10초 이하 경고, 시간 종료 시 자동 제출)
→ 提交订单(제출 후 수정 불가) → 조리 애니메이션(체크한 재료만 그릇에 투입)
→ 결과(你的价格 + 발표 문장, 목표 가격 입력 시 相差 계산) → 下一轮(새 주문서)

결과 판정(목표 가격을 입력했을 때): 차이 0元 → 恭喜你！价格完全正确！ / 차이 3元 이하 → 太棒了！非常接近！ / 그 외 → 下次再努力！

## 5. (개발자용) 소스에서 다시 빌드
```
npm install
npm run build      # → dist/index.html
```
- `config.js` : 재료·가격 데이터 (빌드 시 index.html에 그대로 삽입)
- `src/icons.js` : 재료 일러스트(SVG)
- `src/OrderSheet.jsx` : 종이 주문서 + 타이머
- `src/Cooking.jsx`, `src/Bowl.jsx` : 조리 애니메이션, 마라탕 그릇
- `src/App.jsx` : 시작 화면, 결과 화면
- `test/e2e.mjs` : 브라우저 자동 테스트 (Playwright)
